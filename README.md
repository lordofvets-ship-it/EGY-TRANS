# تدقيق جودة مكالمات الكول سنتر (QA Call Center Auditor) — v1.5.0

أداة لتفريغ وتحليل جودة مكالمات كول سنتر صيدليات بالعامية المصرية، مع تدقيق ريسيت الفاتورة وتقارير Excel وتحليلات أداء.

## التشغيل
```bash
npm install
cp .env.example .env.local        # ثم املأ GEMINI_API_KEY وكلمات المرور
npm run migrate                    # مرة واحدة: ينظّف تحليلات قديمة محفوظة (ينشئ نسخ .bak)
npm run dev                        # التطوير
npm run build && npm start         # الإنتاج
```

## الجودة
```bash
npm run lint     # TypeScript
npm run verify:gemini   # تحقق من مفتاح Gemini (الاتصال، الصوت، JSON) — شغّله على جهازك
npm test         # 207 اختباراً: وحدات + بيانات حقيقية + مكوّنات + السيرفر الفعلي
```
مجلد `tests/golden` يحوي 17 مكالمة حقيقية محللة تُستخدم كاختبار انحدار.

## الصلاحيات
عند ضبط `APP_ADMIN_PASSWORD` يتطلب النظام تسجيل دخول: **مدير** (كل شيء) و**محلل** (رفع وتحليل وعرض وتصدير، بدون حذف أو نسخ احتياطي أو إدارة الذاكرة).
ماذا تغيّر بالتفصيل؟ انظر `docs/CHANGES.md`.
